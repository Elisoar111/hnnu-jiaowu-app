# 题库练习

不联网、不需要学校账号的刷题插件。内置一份通用演示题库，也支持导入自己的 JSON 题库；
可多选章节、选练习模式，提交后进总结页看正确率与错题明细，错题本与收藏存在本机。

移植自安卓项目 `app/src/main/java/com/hnnujw/course/review/`
（`PracticeSession` / `ChapterOrder` / `QuestionOrder` / `PracticeSummary` / `AnswerSheet` / `WrongBookLogic`）。

## 三个页面

- **题库练习**：选章节 → 选模式 → 开练 → 答题卡 → 提交看总结
- **题库仓库**：看当前装载的题库、导入 JSON 题库文件、恢复内置演示库
- **错题本与收藏**：按错误次数列出做错过的题，显示收藏数量，可清空错题记录

## 怎么用

1. 在开始页勾选章节（**一个都不勾 = 全部章节**）。章节按「第一章、第二章」的自然顺序排列。
2. 选模式：顺序练习 / 乱序练习 / 考试（交卷后统一判分）/ 背题模式。
3. 点「开始练习」。题干下方是选项，点选即可；多选题可以选多项。
4. 点「**确认答案**」揭晓解析。**它只是"现在揭晓解析"，不是"这题算不算数"的开关** ——
   只选了答案、没点确认就往下走，提交时一样会判分。
5. 顶部「答题卡」看整卷状态：○ 未作答 · ● 已选未判 · √ 正确 · × 错误，点格子直接跳题，
   答题卡底部就是「提交」。
6. 最后一题的「下一题」会变成「提交」，或者随时用「结束本轮」，都会进总结页。

## 与安卓端一致的地方

- **判分按钮一律叫「确认答案」**（此前多选叫「提交答案」）。
- **交卷补判**：只选了没确认的题，提交时一并判分并写进错题记录；
  **从头到尾没碰过的题才算未作答，且不算答错**，不拉低正确率。
- **正确率的分母只有已判分的题**（对 + 错），与 `PracticeSummary` 一致。
- **七档鼓励语**：照 `encouragementFor` 的档位与原文搬过来。
- **自动下一题**：多选题不自动跳（程序无从判断"选完了没有"），背题模式也不跳。
- **章节自然序**：按「第一章 / 第 2 章」里的数排序，而不是按文字编码。
- **题库 JSON 格式**：与安卓端 `assets/review/*.json` 兼容（`{version,name,questions:[...]}`、
  裸数组、单题对象都认；`type` 支持 `single`/`multi`/`单选`/`多选`）。

## 平台上做不到、因此改了的地方

| 安卓端 | 插件里的做法 | 原因 |
| --- | --- | --- |
| SQLite 存题库与作答 | 题目放页面 state，错题/收藏放 `storage` | 插件没有数据库；`storage` 每作用域上限 256 KiB，所以导入上限 300 题、单题题干 500 字 |
| 考试限时倒计时 + 到点自动交卷 | 考试模式保留"交卷前不判分、不显示对错与解析"这一半 | 平台没有可靠的前台计时能力 |
| 悬浮球「问 AI」 | 不在本插件内；AI 答疑单独做成了 `ai-tutor` 插件 | 平台没有悬浮窗能力 |
| 间隔复习（下次复习时间） | 只按错误次数排序，不做间隔日程 | 没有可靠时钟，算出来的复习时间不可信 |
| 逐题编辑 / 合并题库 | 未实现 | 导入 + 练习 + 错题本已覆盖主要用途 |

## 权限与数据

- `permissions`: `storage`、`files`
- **完全不联网**（`network` 规则为空）
- 存储键：`bank`（导入的题库）、`progress`（错题次数与收藏）
- 导入的题库文件通过系统文件选择器读取，插件只拿到受限句柄，不拼接任意文件路径
