教务助理 用户手册

版本：适用 v1.2.0 及相近版本 · 系统要求 Android 7.0 及以上（建议 Android 12+，液态玻璃效果最完整）

教务助理是一款面向高校学生的第三方教务客户端，接入了学校的教务系统，把选课、课表、成绩、第二课堂、教务消息等高频操作集中到一个应用里。整个界面采用"液态玻璃"材质：折射、色散、高光都是实时计算的，按下去会形变、松手弹回来。

本文按功能模块完整介绍应用的每一项能力。

1. 安装与首次启动

1.1 安装

从发布页下载 APK 安装包，直接安装即可。安装时如系统提示"未知来源应用"，允许该来源安装。

1.2 首次启动流程

冷启动后，应用会按以下顺序依次引导：

  1. 登录页：首次使用必须先登录教务账号（见第 2 章）。
  2. 功能引导页（Onboarding）：登录成功后的首次启动会播放 4 页横滑引导，分别介绍课表与成绩、选课、第二课堂、账号与会话。可以左右滑动阅读，也可以点「跳过」直接进入。
  3. 设备授权页（激活）：如果当前设备不在授权名单内，会显示你的设备 ID，可以一键「复制设备 ID」发给管理员申请授权，授权后点「重新验证」。开源构建默认放行，此页一般不会出现。

1.3 体验演示模式

登录页提供「体验只读演示模式」：不连接教务系统，使用内置的本地演示数据浏览界面。演示数据只读，不会向学校提交任何操作。

2. 登录与账号

2.1 两种登录方式

登录页顶部有「密码登录 / Cookie 登录」两个分段标签，可随时切换。

密码登录

  • 输入学号和密码，密码框右侧的眼睛图标可以切换明文/密文显示。
  • 当学校要求图形验证码时，会弹出验证码弹窗：显示验证码图片、输入框，以及「看不清？点击刷新」按钮。
  • 常见错误都有明确提示，例如「用户名或密码不正确」「验证码错误」等。

Cookie 登录

  • 在浏览器里登录学校教务后，复制会话 Cookie，粘贴进多行输入框（默认打码显示，可切换明文），提交即可登录。
  • 适合不方便输入密码、或学校需要跳转统一身份认证的场景。

网页登录（内嵌浏览器）

  • 从登录页进入内嵌浏览器，直接打开学校教务登录页，可完整完成统一身份认证（SSO）等网页流程。
  • 浏览器带地址栏（可输入网址或关键词搜索）、进度条、刷新按钮和「教务入口」一键返回。
  • 登录成功后点「完成登录」，应用自动回传 Cookie 并登录。
  • 出于安全考虑，非学校域名的跳转会被拦截并提示；导出的 Cookie 仅限定为学校教务地址。

2.2 入口选择与连通性测试

  • 应用支持「主站」与「备用入口（IP 直连）」两个登录入口，登录页顶部可直接切换，切换不占设备绑定名额。
  • 「测试站点连通性」按钮会对主站和备用入口各探测一次，逐行显示连通/不通、延迟（毫秒）或失败原因（域名解析失败 / 连接超时 / 证书校验未通过 / 无法建立连接）。用它来区分「账号密码错了」还是「学校网络不通」。

2.3 账号绑定与多账号

  • 首次登录一个新账号时会弹出「确认绑定账号」对话框，显示姓名与设备绑定名额，取消则不绑定。
  • 每台设备最多绑定 3 个学生账号（所有版本合计），超限会提示错误。
  • 已保存密码的账号，会话过期时应用会尝试自动续期；学校要求验证码或二次确认时仍需手动完成。
  • 已登录状态下再次冷启动，应用直接进入主页并提示「欢迎回来，XXX」。

2.4 账号管理

「我的」→ 账号与教务 → 「账号管理」把重新登录与账号切换合并在一起，弹窗里固定显示 3 个槽位：

  • 已绑定的账号各占一框，显示姓名、学号、登录方式（密码 / Cookie）、学校、是否已存密码。
  • 点击账号框即可切换到那个账号（当前账号框有高亮标识）；框内也保留了「删除密码」「删除账号」小按钮。
  • 空槽位显示加号，点击会跳转登录页：登录一个新账号后自动绑定到本机（每台设备最多 3 个学生账号，超限会提示错误）。
  • 各账号的队列、课表缓存、自定义课程、提醒、消息未读数彼此独立。
  • 删除密码：只清除保存的密码，保留账号，同时取消自动续期。
  • 删除账号：连同密码、Cookie 和本地课表缓存一起删除，不可恢复；删除当前登录账号会返回登录页。删除账号不会释放设备绑定名额。

2.5 会话失效与重新登录

  • Cookie 失效时页面会出现悬浮提示「需要重新登录 / 正在恢复登录状态」，可一键拉起重新登录页，登录后返回原页面；会话过期弹窗提供「稍后 / 立即登录」。
  • 重新登录已并入「账号管理」：独立入口取消了，当前账号的会话在账号管理里点自己的账号卡即可恢复。
  • 「我的」页的「更新 Cookie」可以手动刷新登录状态（适用于密码登录的账号）。

3. 主界面总览

登录后进入主页，底部导航共 5 个标签：

Tab 内容
课表 周视图课程表（见第 4 章）
选课 可选 / 已选课程 + 选课工作台（见第 5 章）
成绩 学期 / 总体 / 考试成绩（见第 6 章）
二课 第二课堂积分与排行榜（见第 7 章）
我的 账号、外观与各项配置（见第 9 章）

界面行为：

  • 底栏自动收起：页面向下滚动时玻璃底栏自动收缩隐藏，向上滚动或回到顶部时恢复，一屏能多看一节多的内容。
  • 消息红点：有未读教务消息时，「我的」页入口和底部导航会显示红点。
  • 启动首屏：可在「我的」中选择下次启动直接进入哪个页面（默认课表），见 9.4。
  • 减少动效：系统开启"减少动效"（无障碍）后，应用动画自动精简。

4. 课表

4.1 周视图

  • 网格为「时间列（节次号 + 起止时间）+ 周一至周日」7 列；课程卡片显示课程名与地点。
  • 同课程同色：同一门课的所有卡片颜色一致（16 色调色板自动分配），不同课程不会撞色。
  • 卡片上的状态图标：
  • ▶ 播放图标 = 这节课正在上（按节次时间实时刷新）；
  • ⚠ 警告图标 = 与其他课程时间冲突；
  • ✏ 铅笔图标 = 自定义添加的课程（补课生成的课程不显示铅笔）。
  • 顶部标题显示「第 N 周」和今天的日期，浏览非本周时标注「(非本周)」。星期条下方显示每天的日期：本周高亮今天，非本周高亮周一作为锚点。

4.2 切换周次

  • 点顶栏的左右箭头切换上一周 / 下一周（第 1–25 周）。
  • 也可以在网格上整页左右横滑翻周，带缩放视差动画。

4.3 课程详情

点击任意课程卡片，从卡片位置弹出底部详情弹层：

  • 上课时间、地点、教师、周次范围。
  • 冲突提示：说明与哪门课在第几周第几节重叠。
  • 冲突选课（本节上哪门）：当这节课与其它课程时间冲突时，详情弹层会列出全部候选（本节课 + 与它撞车的课）。点选要上的那门，另一门会在课表格子里让位隐藏。选择按"节"记录——两门课只有部分节次重叠时，只有真正重叠的那几节让位，其余时段互不影响；选择按账号保存，冷启动后仍生效。点「清除选择 · 显示全部冲突课程」可一键恢复全部显示。
  • 补课 / 调休生成的课程会显示来源说明（对应平时星期几的课）。
  • 课程提醒开关：开启后默认上课前 15 分钟提醒，并显示下次提醒的具体时间；权限不足时提供「设置提醒权限」引导，缺少学期时间时提供「设置学期时间」引导（详见第 10 章）。
  • 自定义课程额外有「编辑课程」按钮和「更多课程操作」菜单（删除课程）。删除后有 5 秒「撤销」 Snackbar，课程和提醒会一起恢复。

4.4 补课（调休）

当某天的课因为节假日调到周末时，用补课功能把课"搬"过来：

  1. 点击星期条上的「六 / 日」格子（补课入口在这里，不是按钮）。
  2. 弹窗里用滚轮选择「补第几周」「补星期几」，下方会实时预览「第 N 周 · 星期X 的 M 门课 → 第 N 周 周六」。
  3. 点确认后，那一天的全部课程按原时段生成到当前浏览周的周末格子；同一格重复补课会自动合并周次，不会叠加出重叠卡片。
  4. 补课生成的课程默认不排提醒，但会生成一条提醒记录，可在课程详情里一键开启。

4.5 自定义课程

课表设置页可以添加不属于教务系统的课程（社团、自习等）：

  • 字段：课程名称（必填）、教师（可选）、地点（可选）、星期（1=周一…7=周日）、开始节次、结束节次、周次（支持「1-16周(单),18周」这类写法）。
  • 时间重叠时不会阻止保存，但会列出冲突课程提示「时间重叠，仍可保存」。
  • 自定义课程按账号隔离保存，可随时编辑或删除。

4.6 导出课表到日历

顶栏的分享（导出）按钮会把当前学期课表生成 iCal（.ics）文件并调起系统分享，接受方选择系统日历即可导入。未设置学期开始日期时会先引导去设置；空课表无法导出。

4.7 课表设置

课表页顶栏的齿轮进入课表设置页：

设置项 说明
添加 / 编辑 / 删除自定义课程 见 4.5；补课生成的课程也会出现在这个列表里，可删除
第一周开始日期 滚轮选择开学第一周的周一；副标题会显示当前生效日期是「已按你的设置」还是「按学期推算」（秋季默认 9 月 1 日、春季默认 3 月 1 日所在周的周一）
每天节数 滚轮选择 8–16 节
课表字号 小 / 标准 / 大 / 特大 四档（0.85–1.30 倍）；只放大缩小课表文字，不改网格布局，改完立即生效、按账号保存
同步课表 从教务系统重新拉取当前学期课表
节次时间 点任意一节弹出时间范围滚轮选择器，修改该节起止时间

小贴士：如果课表"日期不显示"或周次对不上，优先检查「第一周开始日期」——「我的」页副标题会告诉你当前用的是什么日期、来自哪里。

5. 选课

选课 Tab 内含「可选 / 已选」两个子页和选课工作台。

5.1 可选课程列表

  • 顶栏：「可选 / 已选」分段切换，以及搜索、刷新、筛选三枚圆钮；副标题显示学校与教务系统名称。
  • 轮次选择器：切换「全部轮次与分类」或具体选课轮次；学校未开放选课时会显示官方提示（如「当前不属于选课阶段」），退选阶段仍可查看课程并办理退课。
  • 搜索：按课程名 / 教师 / 课程号 / 教学班模糊匹配。
  • 课程分组卡片：显示课程名、学分、教学班数和状态徽章（已选 / 名额紧张 / 名额未公布）；点击展开全部教学班。
  • 教学班行：显示教学班名、教师、上课时间、地点和余量（已选/容量；余量 ≥85% 黄色预警、满员红色、未公布显示 --）。

5.2 选课操作（对某个教学班）

操作 方式 效果
立即选课 点击教学班行 → 确认弹窗 直接提交选课，结果以提示反馈（成功 / 已选 / 暂无余量 / 课程冲突 / 超出学分限制 / 需要验证码 / 结果待确认等）
设为目标课程 教学班行上的旗帜按钮 设为精确匹配目标：锁定这个教学班反复尝试
设为监控目标 教学班行上的定位按钮 设为模糊匹配（捡漏）目标：盯同课程的所有教学班，有人退课立刻顶上
加入选课队列 教学班行上的加入按钮 放进选课队列按顺序执行
长按教学班行 长按 进入多选模式，可全选、批量入队、批量选课

批量选课按顺序逐门提交；遇到验证码、登录失效或"结果待确认"会自动停止后续提交，防止误操作。

5.3 筛选面板

筛选按钮打开玻璃浮层面板，筛选维度由学校接口动态提供，最多可达 13 个：开课部门、年级、学院、专业、课程类别、课程性质、课程归属、教学模式、上课时间（多选）、上课节次（多选）、重修标记、教材、教学班名称。

  • 面板底部有「已选 N 项」徽章和粘性的「重置 / 应用」操作栏。
  • 应用后列表顶部出现已激活筛选的标签栏，可单独删除某个标签或一键「清除筛选」。
  • 下滑面板标题区或点击面板外部即可关闭。

5.4 已选课程

  • 列出通过自主选课选上的课程：学分徽章、教师、时间、地点、教学班、课程号。
  • 退课：点垃圾桶图标 → 红色「确认退课」弹窗（提示退课后可能无法再次选上）→ 提交；退课进行中顶部显示红色进度条。
  • 学校统一排课的课程不在此列表，请在课表查看；不可退的课程显示「已选」徽章，全部不可退时提示去教务网页办理。

5.5 选课工作台

第 2 个 Tab 是选课工作台，核心是"任务 + 队列 + 定时 + 监控"。

任务总览卡：显示当前任务标题、状态（执行中 / 定时待命 / 执行完成 / 准备就绪 / 等待添加等）和副标题（按队列顺序执行 / 并行处理最多 2 门 / 持续监控）。三个实时计数器：尝试 / 成功 / 失败。

三种模式（任务卡上的分段切换）：

模式 用途
精确执行 对指定的教学班反复提交，直到成功或达到次数上限
模糊监控（捡漏） 盯同课程的所有教学班，有人退课立刻顶上
定时模式 设好开始时间，到点自动开始执行

课程队列：

  • 每项显示课程名、教学班 / 教师 / 时间摘要、状态（待命 / 执行中 / 已成功 / 未成功）。
  • 每项可上移 / 下移调整执行顺序、删除、点击切换单条的智能/精确匹配。
  • 队列头部有数量、全局「智能 / 精确」切换和清空按钮。
  • 添加课程：底部按钮或任务坞快捷键打开手动添加弹窗——课程名称必填，教学班、教师、上课时间（周几 + 节次）选填；重复添加会提示。也可以在课程列表长按批量入队。

定时模式：

  • 输入课程 / 教师关键词，用玻璃滚轮日期时间选择器选「计划开始时间」；开始时间必须在未来。
  • 首次启用会弹风险提示：系统电池优化 / 锁屏可能让定时延迟，建议把应用加入电池白名单；可勾选「不再提示」。
  • 定时基于系统精确闹钟 + 前台服务双保险；设备重启后闹钟自动重排；需要「允许精确闹钟」权限，不足时引导跳系统设置。
  • 可一键取消定时任务。

高级设置（折叠卡，标题摘要显示「间隔 · 次数」）：

  • 重试间隔（毫秒，默认 1500，最低 500）；
  • 最大重试次数（默认 100，最多 1000）；
  • 并行执行开关（队列多于 1 门时可用，最多同时 2 门）；
  • 队列匹配方式智能 / 精确切换。

运行日志：可展开的等宽字体控制台，每条带时间戳，最多保留 100 条，可清空。

任务操作坞：底部的玻璃圆钮即主按钮，文案随状态变化——「开始执行 / 停止执行 / 创建定时任务 / 取消定时任务 / 开始监控」；旁边展开 6 个快捷操作：添加课程、切换模式、设置定时、高级设置、运行日志、课程队列。

学校返回的提示（例如"间隔至少 500 毫秒，每门最多 1000 轮"）会直接显示在页面上。开始执行前应用会请求通知权限；执行由前台服务驱动，通知栏常驻。

6. 成绩与考试

成绩 Tab 有三个子页：学期 / 总体 / 考试（玻璃分段条，上划收拢为悬浮条，各页独立记忆滚动位置）。

6.1 学期成绩

  • 顶部学期选择器：近 4 学年的全部学期，最新在前。
  • 统计条：平均绩点（按学分加权自动计算）、总学分、课程数。
  • 课程列表：课程名 + 课程代码/开课学院，右侧学分和大号成绩；成绩按分数段着色（90+ 绿、80+ 蓝、70+ 橙、60+ 主体色、不及格红）。
  • 点击课程卡片展开：平时 / 期中 / 期末分项进度条（缺失的期末分会按总评自动反推）、绩点 / 学分 / 课程性质 / 教学班信息芯片、备注。

6.2 总体成绩

  • 统计条：累计绩点、已修学分、总课程数。
  • 成绩分布卡：优 / 良 / 中 / 及各分段彩色条形与计数。
  • 全部课程明细，同样可点击展开。

6.3 考试安排

  • 考试数统计条 + 按时间排列的考试卡片：考试名称（期中标橙色）、考试时间、地点 + 座位号、教师。

6.4 导出成绩单

学期 / 总体页顶栏的分享按钮可导出 CSV 成绩单（学年、学期、课程名称、课程代码、开课学院、学分、成绩、成绩分项），调起系统分享。

7. 第二课堂

第 4 个 Tab 是第二课堂（到梦空间 / 二课平台）的查询视图。

7.1 登录

  • 学校接入二课后，首次进入会引导「登录第二课堂」。
  • 账号固定为教务学号（只读），密码默认预填学校初始密码：学号 + &Zhtx，改过密码可直接覆盖输入。
  • 登录成功后保存凭证（系统密钥库加密、仅存本机），失效时自动续期；已保存密码后，登录弹窗变为「删除已保存的第二课堂密码」。
  • 应用只做查询，报名、申报请回官方站点办理。

7.2 成绩单与积分

  • 头部显示姓名、学号/年级、学院·专业，以及两个统计：学分、总积分。
  • 「各模块积分状况」逐行显示每个模块的我的积分 / 学校要求值，进度条按完成度着色（未达标红 / 接近主题色 / 达标绿），并附「全校参考」值。

7.3 排行榜

  • 四级分段切换：班级 / 专业 / 院系 / 全校；顶部有「我的排名」卡片（第 N 名或未入榜 + 分数）。
  • 班级层级展示完整榜单：前三名金银铜名次徽章、姓名、专业、分数。
  • 专业 / 院系 / 全校层级只显示自己的名次。
  • 名次按积分重新计算，同分并列共享名次、不跳号。
  • 隐私：「我的」页的「显示班级同学排名」开关关闭后，班级榜单隐藏同学名单，只保留我的排名。

8. 消息中心

从「我的」页「消息中心」进入（有未读时入口带红点和数量）。

  • 未读 / 已读分组：顶部玻璃分段切换，标签上直接显示条数（如「未读 3」），默认停在未读。
  • 消息行：未读蓝点、标题加粗、发送者与发送时间、两行摘要；组内按时间倒序。
  • 点开即已读：点击消息乐观标记已读，全局未读数当帧刷新（红点同步消失）；详情页展示完整正文，列表已带正文的消息就地展示不再二次请求。
  • 离线优先：先展示缓存再刷新；错误态可「在教务网页查看」跳内嵌浏览器。
  • 新消息通知：应用回到前台时按 30 分钟节流检查教务消息，有新未读时发系统通知（每 12 小时也会后台巡检一次）；设备重启、应用更新后自动重排巡检。

10. 课程提醒

每门课都可以单独设置上课提醒。

  • 入口：课表 → 课程详情弹层 → 「课程提醒」开关。
  • 默认提前 15 分钟，可在 0–1440 分钟范围内调整。
  • 通知内容：「课程名 · 即将上课」，正文为地点 + 第 N-N 节；点击通知直达课表页并打开该课详情。
  • 生效条件（缺一不可）：已授予通知权限与精确闹钟权限、通知渠道未被关闭、课程有有效周次、已知第一周周一日期与节次时间。缺哪一项，详情页会显示对应的引导按钮或文案（如「待授权：允许通知和精确闹钟后生效」「待补全本学期第一周周一日期或节次时间」「本学期没有后续课次」）。
  • 提醒基于系统精确闹钟，应用被杀也能响；自对账机制：切换账号、同步课表、编辑/删除课程、开机、系统时间变化后会自动重排或取消过期闹钟，删除自定义课程时提醒一并删除。

11. 通用操作与使用技巧

  • 长按：课程列表长按教学班 → 批量多选（全选 / 批量入队 / 批量选课）；课表补课入口是点击星期条的「六 / 日」。
  • 下拉刷新：可选课程、已选课程、消息中心等列表页支持下拉刷新，加载中有骨架屏。
  • 撤销：删除自定义课程后有 5 秒撤销窗口。
  • 点击展开：成绩卡片点击展开分项成绩；课程分组点击展开教学班。
  • 通知直达：课程提醒通知点击直达对应课程详情；课程提醒失效时会明确提示。
  • 自动恢复：登录态失效自动提示并可在恢复后回到原页面；课表同步失败时保留本地数据。
  • 账号隔离：队列、定时任务、课表缓存、自定义课程、提醒、消息未读、二课凭证全部按账号隔离。

12. 数据与隐私安全

  • 密码存储：账号密码经 Android KeyStore 的 AES/GCM 加密后仅保存在本机，加密或读取失败一律按"未保存凭据"处理，不会明文落盘。
  • 不上传隐私：应用没有使用统计、没有行为上报；不收集学校、学号、课程内容或设备信息。
  • 云备份收紧：账号密码密文与会话 Cookie 文件已从系统云备份和设备迁移中排除，不会随备份扩散到其他设备。
  • 日志脱敏：运行日志只记录 Cookie 名，不记录 Cookie 值和明文密码，可放心导出分享。
  • 网络严格校验：HTTPS 证书走系统信任链严格校验；明文 HTTP 仅对备用 IP 入口放开。
  • 图片本地处理：头像与壁纸仅在本地裁剪、压缩和存储，不上传。

13. 常见问题 FAQ

Q1：登录不上怎么办？
先点登录页的「测试站点连通性」：主站和备用入口都通 → 检查账号密码或验证码；主站不通、备用通 → 切换到备用入口（IP 直连）再登录；两个都不通 → 多半是校园网/学校服务问题，稍后再试。密码登录始终不行时，可用「Cookie 登录」或内嵌「网页登录」绕过客户端登录流程。

Q2：课程提醒不响？
按顺序检查：① 通知权限是否允许；② 是否授予「精确闹钟/闹钟和提醒」权限；③ 课表设置里「第一周开始日期」是否正确；④ 该课在本学期是否还有后续课次。详情页的提醒开关下方会写明当前缺哪一项。

Q3：课表日期或周次对不上？
去课表设置检查「第一周开始日期」。副标题会显示当前生效日期及来源（"已按你的设置"或"按学期推算"），手动设置一次即可纠正。

Q4：定时选课到点没跑或跑晚了？
多为系统省电策略拦截。请把应用加入电池优化白名单 / 允许后台自启动，并授予「精确闹钟」权限；定时任务创建时也有此风险提示。同一账号重复创建定时任务会覆盖前一个。

Q5：余量显示「--」是什么意思？
学校没有公布该教学班容量，客户端不猜测。选不选得上以学校实际结果为准。

Q6：退课按钮点不了 / 没有这门课？
「已选」列表只包含通过自主选课选上的课程；学校统一排课的课请在课表查看，退办请到教务网页。退课是否开放由学校轮次决定，退选阶段仍可查看课程并办理退课。

Q7：批量选课怎么中途停了？
遇到验证码、登录失效或"结果待确认"会自动停止后续提交，这是防止误操作的刻意设计；处理完对应情况后重新发起即可。

Q8：二课密码是什么？
学校初始密码为「学号 + &Zhtx」，登录框已自动预填；改过密码就输入新密码。应用只做查询，报名请回官方平台。

Q9：怎么换图标头像 / 换背景？
「我的」页点头像 → 相册选图 → 取景框裁剪；背景在 「我的」→ 外观 → 背景，支持预设、纯色、图片三种来源，图片可调模糊与蒙版。

Q10：有新版本吗？
「我的」→ 「检查更新」可直接获取最新版本与更新说明；也可以到发布页下载最新 APK 覆盖安装；当前版本号在「我的」页页脚。

Q11：遇到 Bug 怎么反馈？
可通过「我的」→ 导出日志获取运行日志（已脱敏），连同问题描述发送给作者邮箱。
