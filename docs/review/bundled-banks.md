### 1. 马克思主义基本原理（300 题 · 来源 pptx）

- **选项只在 `答案：` 行之前收集**：slide32 在 `答案：D` 之后还有 3 行

  这些补充标注改为并入该题 `explanation`。
- 题干里的空括号 `（\xa0\xa0）`（不换行空格）已全部剔除。

**已知缺漏**：

### 2. 思想道德与法治（258 题 · 来源 docx）

- 全文 855 个非空行，用 `^第[一二三]部分` 精确定位，只取「第一部分 选择题」到
  「第二部分 辨析题（明辨）」之间的内容；后半的辨析题/简答题按要求**未纳入**。
- 7 个章节：绪论 + 第一章~第六章。

题数构成：245 道常规题号（`.`）+ 6 道用 `、` 作题号分隔符 + **6 道从选项行尾部拆分** + **1 道原题号缺失** = 258。

处理掉的格式坑：

1. **题号粘连**（6 处）。形如
   `A.文化建设 B.经济建设 C.政治建设 D.法治建设9.没有崇高的( C )，...`
   ——选项 D 末尾直接粘着下一题题号。解法是选项切分后检查剩余尾巴是否匹配 `^\d+[.．、]`，
   匹配则拆开，题号部分作为下一题开头。**没有**采用「整行必须以数字开头才算题干」的规则，
   否则这 6 道题会整题丢失。拆分时要求切点前至少已有 2 个选项标记，
   以免把「B.爱国主义与爱社会主义是可以割裂开的」这类含数字的选项正文误切。
2. **三种答案标记形态**。正则 `[（(][\s\u00a0]*([A-Ha-h]...)[\s\u00a0]*[）)]`
   同时容忍全角/半角括号与内部普通空格、`\u3000`、`\xa0`，可识别
   `（A）`、`（  B  ）`、`(  A  )`、`（\xa0D\xa0 \xa0）`；出现 0 个字母时视为「答案在别处」。
   匹配到的括号均从题干中剔除（校验已确认 0 残留）。
3. **题号分隔符混用**：`.` / `．` / `、` 三种都出现。
4. **一行多个选项**：用位置切分（`finditer`）而非 `split`，因为 `split` + 捕获组会吃掉
   `A.` 的分隔点，导致前缀 `A` 粘在选项正文上变成 `A爱人民`。选项前缀已全部剥离。
5. **选项标记紧跟汉字且无空格**：`B.世界的本源是什么C.人应该怎样对待生活`
   ——`C.` 前无空格，早期用「前面必须是空白」的回顾断言会漏切；改用
   「前面不能是字母/数字/句点」的否定式断言。
6. **选项分隔符含 `、`**：`C．科学社会主义理论 D、时代精神`。
7. **题干跨行**（1 处）：`1.法律规范区别于道德` / `规范、纪律规范等其他社会规范的一个重要特征是（ A ）`
   ——答案在续行里，向后吸收续行直到找到答案括号后合并。
8. **一题两个空括号**（2 处）：如
   `有敢为人先、开拓进取的（ C ），有逢山开路、遇河架桥的（ C ）`
   两个空由**同一个选项**填（组合型单选），已识别为 `single` 而非 `multi`。
9. **原题号缺失**（1 处）：`自古以来…马克思主义道德起源观是（ D ）。 A.…B.…C.…D.…`
   原文缺 `52.`，靠「以散文开头（非选项标记开头）+ 含答案括号 + ≥3 个选项标记」识别为独立题。
   该守卫同时避免了把坑 1 的粘连选项行误判成独立题。

**已知缺漏**：
- 源 docx 内**没有任何**「答案：」独立行或「解析：」行，故 258 题 `explanation` 全为空。
- 全部为单选，源文件无多选题（所有答案括号内均只有 1 个字母）。
