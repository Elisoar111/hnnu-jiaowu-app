## 2. 功能提案（按「数据已就绪 × 用户价值」排序）

> 关键判断：**下面每一条都不需要新增网络抓取** —— 数据要么已在本地库里，要么现有接口已经返回、只是没被用起来。这是本项目做功能的最大优势。

### 2.1 低垂果实（合计约 3 天，建议第一批）

**① 课表图片分享** ⭐ 最推荐　~1 天

现状只有「导出 .ics」「导出 .xlsx」（`ICalExporter` / `ScheduleExcelIO`）。同学之间传课表实际用的是**截图**，而截图会带状态栏、留白，暗色模式下还难看。

做法：把课表 Composable 渲染成 PNG（`drawToBitmap` 或直接画到 `Canvas`），带学期名、周次、可选二维码指向下载页，走 `ACTION_SEND`。可做「本周 / 单日」两种范围。

价值：**每个人每学期至少用一次**，且渲染层已有，不需要新数据。

**② 空教室 × 课表 =「现在能去哪自习」**　~1.5 天

`emptyroom` 能查指定时间段的空闲教室（`EmptyRoomParser` + 分页），`schedule` 里有当前课表 —— 但两者**从未交叉**。用户现在的实际困难：查空教室要自己输时间段，再脑补自己有没有课。

做法：以「当前时段」为默认，交叉掉自己正在上的课，输出「你 10:00–11:40 没课，以下教室空着」，按楼栋/容量排序（用记忆的常去楼栋，不申请定位权限）。

**③ 考场座位卡**　~0.5 天

`AcademicExam` 已带 `seat`（座位号）、`examName`、`teacher`、`time`、`location`，但考生最关心的**座位号**现在只有列表里能看到。

做法：考前提醒通知正文带「明天 08:00 · 教三 302 · 座位 27」；首页卡片显示「下一场考试」倒计时 + 座位。

### 2.2 成绩与学业（2–4 天）

**④ 成绩统计与趋势**　~2 天

数据齐全：`AcademicGradeReport`（GPA、总学分）+ 每条成绩已有 `credits` / `gradePoint` / `type` / `term`。现在只有一个列表。

- 按学期 GPA 折线、学期均分对比
- 学分构成：必修 / 选修 / 重修，及格与不及格分开
- **绩点模拟器**：「这学期剩 3 门，要拿到目标 GPA 需要平均 87 分」——纯本地计算，保研/评奖前必算

**⑤ 二课积分缺口**　~1 天

`SecondClassPointAnalysis` 已能算分类/学期账本与「未解释差额」，缺的是**目标对比**。

⚠️ 学校未提供毕业要求数值（代码里没有培养方案接口），所以**让用户自填目标**（如「二课需 60 分」），应用算缺口与「剩余学期每学期至少参加几次活动」。不编造任何学校要求。

**⑥ 历史学期归档**　~2 天

`AcademicStudyCatalog` 已能列多个学期。做「学期快照」：把某学期课表 + 成绩 + GPA 存一份，之后可回看「大二上我都上了什么、考了多少」，也能做学期之间对比。

### 2.3 一卡通（2–3 天）

**⑦ 消费分析**　~2 天

`YktBillRecord` 有 `merchant`、`location`、`title`、`amountCent`、`typeFrom`，站点还有 `turnoverType` 分类字典（`YktClient` 注释已记）。流水现在只是平铺。

做：月度支出汇总、按商户/地点分类饼图、食堂 vs 超市占比、月末预算提醒（阈值用户自设）。

**⑧ 余额趋势与充值预测**　~0.5 天

电费/卡余额每次巡检都算过（`YktAlertStateStore` 存了余额），但只用于节流判定。顺手记一条「余额-时间」序列，就能算「按最近 7 天消耗速度还能用 X 天」——比「低于 20 元」更有用。

### 2.4 题库与 AI（3–4 天）

**⑨ 薄弱章节诊断**　~1 天

`ReviewDatabase` 有按章节的答题记录与 `wrong_book` 掌握等级，但没有聚合视图。做章节正确率热力图 +「你最弱的 3 个章节，去练这 20 题」一键进入。

**⑩ AI 生成相似题**　~1.5 天

`AiChatClient` 已可用。对错题让 AI 出 3 道同知识点变式题，本地存成临时练习（不写入题库，除非用户点「收进题库」）。

⚠️ 入口处必须写明「会消耗你的 API 额度」，默认一次只出 3 题。

**⑪ 题库导出格式扩展**　~0.5 天

现在错题可导纯文本。补 CSV / Anki（`front;back;tags`）两条，方便用别的工具复习。

### 2.5 体验与搜索（3–5 天）

**⑫ 全局搜索**　~2 天

课表课程、题库题目、教务消息、设置项分散在四处，各搜各的。做一个入口统一搜（本地数据 + `AcademicMessage`），结果分组跳转。

**⑬ 消息中心增强**　~1.5 天

`AcademicMessage` 有 `title/sender/sendTime/read`。补：按已读/未读与时间筛选、批量标记已读、关键词过滤、长按复制。

**⑭ 通知免打扰时段**　~1 天

现在课程/考试/成绩/消息/电费/复习六条提醒各有开关，但没有「夜里别响」。加统一 DND 时间窗（如 23:00–07:00），窗内非紧急提醒顺延到窗后。

**⑮ 下节课倒计时条**　~0.5 天

`ScheduleCourseUi` 已有 `isCurrent`。补一个「下节 高等数学 · 14:00 · A101，还有 25 分钟」的细条，只在课表页显示。

### 2.6 大件（先立项，不排期）

**⑯ 平板 / 折叠屏布局**　~3 天

targetSdk 35 的 edge-to-edge 已适配，但大屏仍是单列。做双栏（左课表右详情）与更大字重适配。

**⑰ 跨设备迁移体验**　~2 天

备份/恢复已有（`BackupManager`）。补：备份到用户自选网盘目录的引导、恢复时「合并 vs 覆盖」选择、恢复后自动重排提醒。

**⑱ 课程表导入他人分享**　~2 天

现在能导出 `.ics`/Excel/图片（①②），反向导入只支持 Excel 自定义课表。做「导入同学分享的 JSON/图片」需要 OCR 或自制格式，成本较高，先看需求。

## 3. 明确不做（已有决策，避免反复讨论）

| 项 | 理由 |
|---|---|
| 学习打卡 / 连续天数 | 用户 2026-10-18 明确否决 |
| 选课 / 抢课 | 协议层已于 2026-10-19 删除（从未接界面、零覆盖）；真要做须按当时页面重写 |
| AI Key 静默续期 | 合规口径：凭据类操作必须用户显式触发 |
| 差量更新 | 包体已 9.8 MB，收益不成立 |
| 上架应用商店 | 需要企业资质与隐私合规材料，个人维护不划算 |
| 多语言 | 单校单一语种场景，无收益 |
