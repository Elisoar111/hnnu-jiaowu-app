## notes

这一版最要紧的一条是修好了「课程提醒开了却从来不响」。如果你之前觉得课表提醒没什么用，请再试一次——它现在真的会响了。

课程提醒需要知道「本学期第一周是哪天、每节课几点开始」才能排出闹钟，而其中的节次时间**从来没有被写进去过**：应用只写了日期。缺了节次时间，提醒就一条闹钟都排不出来，界面上却还显示「已开启」。现在提醒会自动从「课表设置 → 节次时间」补齐，**老用户不用做任何操作**，下次打开应用就会自动恢复。

考前提醒也能自动拉到考试列表了。以前只有你自己点开「成绩 → 考试」那一页，应用才知道你有哪些考试，从不点那个标签页的同学永远收不到考前提醒。现在它挂在每 12 小时一次的后台巡检上顺带刷新，每 6 小时最多拉一次，不会给学校服务器添负担。

成绩推送、教务消息、电费提醒、考试提醒这四条推送，原先都是「先把这件事记成已处理，再去发通知」。一旦通知权限被关，这条消息就永久消失，事后重新打开通知也补不回来。现在统一改成「先确认真的发出去了，再记账」：通知关闭期间产生的新成绩、新消息，重新打开通知后仍会补发一次。

题库练习修掉了几处会悄悄算错的地方。

同一道题会被重复计数：点「确认答案」→「再想一下」→ 再确认，这道题会被记录两次。「连续答对三次即掌握」因此被刷穿——点三次就能把一道题刷成「已掌握」，而你实际只答对了一次；题库详情页的正确率也会因为分子超过分母而恒等于 100%。

刚答错的题会被排到第二天，所以「今日待复习」永远是 0 题，那个入口实际上形同虚设。现在答错即进入今日复习队列。

大题库（上千题）的抽题、交卷、首页概览都快了一档：抽题不再把整库题干读进内存，交卷补判的记录写入从每题两次查询压到每库一次，首页概览的六次查询合并成一次。

题库练习还多了五样东西。

**继续上次练习**：退到首页又回来，可以接着上次那题往下刷，交卷后入口自动消失。

**题目搜索**：逐题编辑页能按题干、章节或答案字母过滤，上千题的库也不用一页页翻。

**错题本导出**：把当前筛选后的错题导出成纯文本，走系统分享，方便打印或整理。

**全部错题**：首页新增跨题库的总入口，不必先想「这道错题在哪个题库里」。

**从 Excel / CSV 导题库**：表头写「题干」和「答案」两列就能导；选项写成一列用竖线分隔，或者分成 A、B、C、D 四列都可以，表头顺序随意，中英文都认。逐行校验，跳过的行会带行号报出来。

限时考试还有个改动：判分后不再当场揭晓对错与解析，只提示「已记录作答」，答案留到交卷后 —— 考试中途看到「答错了 + 正确答案」等于提前泄题。

答题卡在跨多个章节时会按章分组，几百题时不用再靠翻几十屏找题。AI 设置里新增「追问上下文」开关（默认关），打开后换题不清空问答历史，可以就着刚才那段讲解继续问，代价是每题多带一段历史 token。

另外顺手修了一批细节：题库练习的内置题库总数不再写死、老数据库里统计页遗留的空壳表会在升级时清掉、正确率不再每次重组都全量重算。

这一版还多了几样东西。

**错题复习提醒**：每天 20:00 检查一次错题本，有到期的就提醒你。默认关闭——这是额外的一条打扰，需要你自己在「我的 → 提醒设置」里打开。

**数据备份与恢复**：「我的 → 数据与安全 → 备份数据」可以把题库、答题记录、错题本、收藏、自定义课程与各项设置打包成一个文件，换手机时再恢复回去。备份里**不含**账号密码、登录凭证与 AI 的 Key，所以恢复后需要重新登录一次、重新填 Key。这个文件是明文的，请像对待自己的笔记一样对待它。

**课表直接写进系统日历**：「课表 → 导出 → 直接写入系统日历」，点完就能在系统日历里看到课程，不用再找应用打开 .ics 文件。重复导入不会产生重复课程。

**电费提醒现在也管度数型了**：有些宿舍的电费项目返回的是「剩余电量 312 度」而不是金额，以前这类项目完全不提醒。现在金额与电量各有各的阈值（默认 20 元 / 20 度），按项目实际返回的单位自动选用。

**隐私政策**：「我的 → 数据与安全 → 隐私政策」。逐条写清了应用会碰到哪些数据、它们存在哪、发给谁，以及每一项权限用来做什么。这份说明按代码实际情况编写，你可以在开源代码里逐条核对。

**悬浮球换成了「AI」字样**：原先是个对话气泡图标，在刷题界面里更像「反馈」或「聊天室」，看不出是「问 AI 这道题」。

安装包从 26.5 MB 降到 **9.8 MB**，主要是把内置字体按实际用到的字符集裁了一遍（常用汉字与标点全部保留，不会缺字）。同时把目标系统版本提升到 Android 15，适配了新版系统的全屏布局与安全策略。

修掉的问题里还有几处值得单独说。

**切换账号后可能看到上一个账号的成绩**：成绩推送用的身份里带了「这一行在列表里排第几」，而教务列表是会插入的——重修、补考成绩插到中间，后面每一行的序号都会变，于是全被当成「新成绩」播报一遍。现在改成按课程本身的字段识别，插入新行不再影响其它行。

**后台刷新拿到的登录凭证没有存下来**：教务每访问一次可能换一张新凭证，而后台巡检拿到的新凭证只留在内存里。下次冷启动会从本地恢复出一张**可能已经作废的旧票**，表现就是「刚收到消息通知，重进却提示登录失效」。现在会存下来了。

**登录凭证不再明文保存**：它等同于登录状态——拿到它的人能读你的学号、成绩、课表、余额，不需要密码。现在用系统密钥库加密后才落盘，退出登录与删除账号时一并清除。

**网页登录页不再允许混合内容**：教务主站与一卡通登录页都是 https，之前却允许它们加载 http 资源，等于给中间人留了一个注入口。现在 https 页面一律禁止，只有学校那两个确实只有 http 的站点（教务备用入口、学工系统）才放宽——不放宽它们会整页白屏。

**刚答错的题以前会被排到第二天**，所以「今日待复习」永远是 0 题，那个入口实际上形同虚设。现在答错即进入今日复习队列。

**同一道题以前会被重复计数**：点「确认答案」→「再想一下」→ 再确认，这道题会被记录两次，「连续答对三次即掌握」因此被刷穿，详情页正确率也会恒等于 100%。

另外还修了几处静默失败：解析成绩或考试列表出错时，以前异常被直接吞掉、页面显示「少了几门课」，现在会留下日志；一卡通记住的房间选择如果与学校的新配置对不上（级数没变但含义变了），以前会拿旧值去查——等于查到别人的房间，现在会逐级校验后丢弃。
