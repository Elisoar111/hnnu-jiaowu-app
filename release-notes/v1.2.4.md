# v1.2.4 更新说明

## notes

先说一件大事：应用正式更名为「校园助理」。名字变了，图标、数据、账号都不变，桌面图标会以新名字显示。

这一版把两件原来「只能看」的事变成了「能办」：学工系统的请假与去向登记、第二课堂的奖励申报，现在都可以在应用里直接填表提交，不用再打开官网。

学工系统从「我的 → 校园服务 → 学工系统」进入。日常请假页顶部写明校方当前是否开放申请、请假是否要求定位打卡（要求时会写出允许的偏差距离），开放时点「写请假」在线填表：请假类型、起止时间、是否离校、事由、紧急联系人逐项填写，还能上传请假附件，提交后回列表等审批结果。节假日去向登记改为「登记单」视角：校方开放的批次列在最上面，登记窗口内的批次点开即可在线填表提交；已提交的登记点开看完整字段（去向类型、离开与返回时间、去向地址、交通方式、家庭所在地、本人手机与紧急联系人）。账号是你的学号，自动带入不用手输；密码是学工系统自己的那一个，与教务密码不一定相同，登录状态失效时会用保存的密码自动重连一次。审批状态按站点返回的原始状态码展示，应用不替你下「已通过 / 已驳回」这类结论，要看审核意见请到官方页面。

第二课堂的「申报」拆成「未申报 / 已申报」两栏。「未申报」列出当前可申报的项目，可按类型与分类筛选、按名称搜索；点开项目看认定档位与说明，点「立即申请」进入填报：选择奖项档位、填写起止日期与总结报告、关联已报活动、上传证明材料，确认后直接提交，全程不用打开官网。「已申报」汇集你提交过的申报记录，含项目名、认定档位、所属模块、认定学时与状态，点开看完整字段。

退到后台也会检查更新。以前只有应用开着的时候才会去查新版本，退出之后就没动静了；现在退到后台之后，系统每天还会替你查一次，发现新版本直接发一条通知，点通知就能看更新说明并下载。这一项依赖系统通知权限 —— 如果通知被关掉了，就只剩打开应用时的检查。

应用内用户手册同步更新：学工一章改为可提交的写法，第二课堂一章补充在线申报的完整流程，应用名称相关文案全部更新为「校园助理」。

反馈渠道：「我的 → 联系开发者」可以直接发邮件给作者；进不去 GitHub、没法在上面提 issue 的同学，欢迎加入 QQ 频道 pd32446534。

感谢每一位使用与支持本项目的同学。

## changelog

### 新增

- 应用更名为「校园助理」（原「正方教务助理」）：`strings.xml` 的 `app_name`、设置页与引导页文案、README、发布流水线公告全部同步；图标、包名、数据与账号不变。
- 学工日常请假可提交：`XuegongClient` 新增 `dailyLeaveForm()`（`GET /DailyLeave/Get?isExam=false&id=`，表单骨架、字典与校方默认值原样下发）、`saveDailyLeave()`（`POST /DailyLeave/SaveForm`，`qs` 风格嵌套序列化 `ApplyInfo[Key]=…`，附件写进 `FileList.Imgs`）与 `uploadLeaveAttachment()`（`POST UpFilePath`，multipart 直传字节，成功判据 `et == 1`）。`XuegongScreen` 新增「写请假」填表页：类型 / 起止时间（玻璃滚轮选择器）/ 是否离校 / 同行人 / 事由 / 紧急联系人与电话 / 出行交通方式，全部按 H5 必填规则本地校验后提交。
- 学工节假日去向登记可提交：去向页改为「登记单」视角，批次列表项可点；开放批次经 `GET /HolidayWhereabouts/Get` 拉取草稿（含 `Config` 的登记窗口）后填表提交（`POST /HolidayWhereabouts/SaveForm`，`model[Key]=…` 序列化）。已登记记录点开仍为只读详情。
- 第二课堂申报可提交：`SecondClassroomClient` 新增 `declareProjects()`（`GET /project/home/page/list`，类型 / 分类 / 排序 / 搜索 / 翻页）、`declareCategories()`（`GET /dict/school/system-para`，`fieldType=honor`）、`declareClassify()`（`GET /dict/project/choice-sort`）、`projectDetail()`（`GET /project/detail/info`，含 `optionList` 认定档位）、`uploadDeclareMaterial()`（`POST /import/upload/image`，multipart，`params` 为 `{"type":4}`；该站点前端 `Encrypt` 在当前构建里是恒等函数，无需签名）与 `submitApplication()`（`POST /project/apply/add_3_0_1`，载荷与站点 `subData` 一致）。
- 二课「申报」页拆成「未申报 / 已申报」两栏：未申报栏为项目列表（筛选 + 搜索 + 翻页 + 「立即申请」），填报页含档位选择、起止日期、总结报告、关联已报活动（`myEnrollments` 复用）与证明材料上传（系统文件选择器），提交前按站点规则本地校验；已申报栏保留原记录列表与详情。

### 变更

- 学工页顶栏与底部「只读」提示移除，副标题改为「日常请假与节假日登记 · 可在线提交」；请假页状态卡在可申请时提供「写请假」入口，不可申请时保留校方原因文案。
- 二课申报页顶部说明卡改为「未申报 / 已申报」分段；`myApplications()` 一次拉全的行为不变，仍无翻页。
- 明文 HTTP 白名单维持 `xg.hnnu.edu.cn` 一项，未放宽；学工与二课的新增接口全部走 HTTPS。
