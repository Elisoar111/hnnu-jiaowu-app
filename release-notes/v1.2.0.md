# v1.2.0

## notes

这一版换了新名字和新图标：应用更名为「教务助理」，底栏的「设置」页也改叫「我的」，界面更清爽。首次进入的引导改成了弹框形式，介绍到哪个页面，点一下就直接带你去那个页面。冷启动进入应用时会收到一条「欢迎回来」，「关于项目」里也加上了对原作者的致谢。

功能上，课表时间冲突的课现在可以在课程详情里手动指定「本节上哪门」，另一门会自动让位隐藏；设置里新增了应用内用户手册、检查更新、推荐网站和分享入口。安全方面清理了残留的第三方反馈接口，移除了开机动画，账号管理的空槽位样式也做了统一。

注意：检查更新读取的是 Gitee 仓库的发布信息，仓库还没有发布版本时会明确提示，发版后即可正常使用。

## changelog

品牌与界面：

- 应用更名为「教务助理」，全新应用图标（方形与圆形，五档密度自适应），安装包体积从约 13MB 降至约 4.7MB。
- 「设置」页与底部导航更名为「我的」，相关提示文案同步更新。
- 首次登录引导从全屏横滑页改为液态玻璃弹框：课表、选课、第二课堂、账号四个条目，点哪条直接跳到哪个页面。
- 冷启动进入应用时显示「欢迎回来，XXX」提示。
- 「关于项目」重新排版，分「隐私与安全、项目地址、致谢、反馈与声明」四节展示，并新增对原作者 znjhahaha（zhengfang-apk）的致谢。
- 移除进入应用的开机 Logo 动画，内容直接呈现。

课表与选课：

- 课表时间冲突的课支持「本节上哪门」：在课程详情里点选要上的课，另一门在网格中让位隐藏；选择精确到重叠节次，按账号保存，可一键恢复显示。

设置与工具：

- 新增「用户手册」：应用内离线阅读，主题跟随应用设置。
- 新增「检查更新」：从 Gitee 获取最新版本与更新说明；仓库暂无发布版本时给出明确提示。
- 新增「推荐网站」：四六级报名、学信网等常用入口。
- 新增「分享给校友」。
- 账号管理弹窗的空槽位文案与样式统一。

安全与清理：

- 移除残留的第三方反馈接口代码（hidisiwa.xyz）及其签名密钥配置。
- 公告源与应用内更新检查、CI 发布脚本统一指向本项目自己的 Gitee 仓库。
